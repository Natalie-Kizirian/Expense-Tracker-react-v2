# 📂 Client Tracker v2

A web application designed to help businesses manage their client base efficiently. This app allows users to create, track, and manage client information with ease, using LocalStorage for data persistence.

## 🚀 Live Demo
https://natalie-kizirian.github.io/Client-Tracker-v2/

## 🛠 Tech Stack
* **Frontend:** React.js
* **Styling:** Tailwind CSS
* **Data Persistence:** LocalStorage
* **Language:** JavaScript

## ✨ Key Features
* **Client Management:** Easily add, edit, and delete client profiles.
* **Financial Tracking:** Track revenue from each client to monitor your earnings.
* **Persistent Data:** All data is saved locally using Browser LocalStorage.
* **Responsive Layout:** Works smoothly on both mobile and desktop devices.
* **Clean UI:** An intuitive interface for quick data entry and navigation.

## 💡 What I learned
Building this project gave me hands-on experience with **React State Management** and **LocalStorage API**. I focused on creating a responsive and functional UI while ensuring the application remains lightweight and fast.
